Semana 3: Práctica con LED RGB Físico

Realizamos el montaje físico y la programación en placa de un LED RGB. Configuramos las salidas digitales de nuestro Arduino para alternar de manera continua entre los colores rojo, azul y verde mediante ciclos programados.

Semana 4: Secuencia de Semáforo Automatizado

Diseñamos un circuito de semáforo utilizando tres LEDs independientes (rojo, verde y amarillo) conectados a pines digitales separados.

Semana 5: Montaje Físico de Semáforo

Implementamos el circuito físico del semáforo automatizado en el protoboard. Conectamos tres diodos LED independientes con sus resistencias.

Semana 6: Circuito en Tinkercad con Sensor

Pasamos a una práctica en Tinkercad, implementando un circuito parecido a el de semáforo, con la diferencia de el uso de un sensor para detectar la distancia, utiliando variables de condición para encender las luces LED.

Semana 7: Circuito en Tinkercad con Sensor de Movimiento

Pasamos nuevamente a una práctica en Tinkercad, utilizando ahora un sensor PIR. Este sensor permite que al momento de detectar menos de 200, este enciende la LED roja y màs de 200 enciende la LED azul.
